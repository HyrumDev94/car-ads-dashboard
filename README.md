## Project Overview

This project focuses on building a data-driven dashboard for analyzing car listings and pricing trends. Using SQL for data extraction and Python for analysis, the goal was to create a clean, interactive report that allows users to explore car advertisements based on model, mileage, year, and price.

## Goal

To design an interactive data dashboard that helps stakeholders identify trends in vehicle pricing, mileage, and regional distribution, while improving the data collection and storage process.

## Skills & Tools Used

Programming: Python, SQL

Libraries: pandas, matplotlib, seaborn

Database: PostgreSQL

Visualization: Tableau / Plotly (depending on which you used)

Environment: Jupyter Notebook

## Project Workflow

Data Collection:
Connected to a database of car ads and extracted relevant data using SQL queries.

Data Cleaning & Transformation:
Removed duplicates, handled missing values, and standardized formats for make, model, and price columns.

Exploratory Data Analysis (EDA):
Examined relationships between mileage, price, and age.

Visualization:
Designed charts to show pricing distribution by brand and car age correlation.

Dashboard Creation:
Developed an interactive view allowing users to filter data and view summary statistics.
